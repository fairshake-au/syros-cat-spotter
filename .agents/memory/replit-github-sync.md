Replit's Git pane and the agent's shell git use separate GitHub auth. The Git pane's own "Connect" fixes only the pane; the agent's shell (GIT_ASKPASS, remote `subrepl-*` not `origin`) needs the account-level Connectors page (replit.com/integrations or the workspace sidebar), reconnected with fairshake-au org access granted. The Replit agent has no tool to write into the workspace's Secrets store itself (only a human-entry form), so a self-generated deploy key can't be installed without exposing the private half — don't attempt that path again without a way to set Secrets programmatically. Full diagnosis: docs/runbooks/replit-github-sync.md (SYC-96).
