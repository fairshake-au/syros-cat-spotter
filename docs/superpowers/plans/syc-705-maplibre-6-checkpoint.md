1. maplibre-gl 5.6.2 -> 6.15.0. 6.16.0 was published 2026-10-25, under 2 days old;

3. Worker: v6 locates its worker from import.meta.url; in the Metro bundle that is Expo's
   registry (document.currentScript, null after load) so the URL came out "" and no map would
   draw. scripts/copy-maplibre-worker.js copies the worker to
   public/maplibre/maplibre-gl-worker-<version>.mjs (git-ignored) in `dev` and `build:web`;
   useMapLibre.web.ts calls setWorkerUrl(maplibreWorkerUrl(getVersion())) before the first Map.
4. v6 has no supported() and no default export: dropped the supported() check (constructor
   throws GPUInitializationError without WebGL2 -> 'no-webgl'); namespace picked by checking
   for setWorkerUrl. Fake reshaped to v6.
5. Verified: typecheck clean; full cat-spotter vitest 3112/3112; build:web succeeds, dist has
   maplibre/maplibre-gl-worker-6.15.0.mjs (+ .br/.gz); serve-web serves it 200
   application/javascript (brotli).
