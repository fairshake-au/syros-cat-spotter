# The website lives elsewhere

catspotters.com — the public site, the shared workspace at
admin.catspotters.com, and the source of the one-pagers — moved to its own
repository:

**https://github.com/fairshake-au/catspotters-website**

The history of every file came with it, so `git log` there still answers why
things are the way they are.

This repository is the app: the Expo client in `artifacts/cat-spotter`, the
API in `artifacts/api-server`, and the shared libraries in `lib/`.
