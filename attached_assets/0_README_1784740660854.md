# Assets — images, fonts & logos

**Heads up: this design system currently ships no binary assets.** Everything visual is
either loaded from a CDN or rendered from type/tokens. This folder documents what to wire
up (and what's still missing) rather than holding files.

## Fonts — external (Google Fonts CDN)
No `.woff2`/`.ttf` binaries are bundled. The three families load over the network via the
`@import` in **`fonts.css`** (a copy of `code/theme/tokens/fonts.css`, already pulled in by
`code/theme/styles.css`):

- **Poppins** — display / headings / big numbers (`--font-display`)
- **Nunito** — body / UI text (`--font-body`)
- **Space Mono** — catalog IDs & data (`--font-mono`)

All three include the **Greek subset** (needed for Syros place names). To self-host instead,
download the families from Google Fonts, drop the `.woff2` files here, and replace the
`@import` with local `@font-face` rules pointing at them.

## Logo
**None exists.** No logo/wordmark file was ever provided or created. Wherever a mark belongs,
the brand name is set in Poppins with a 🐾 (e.g. `🐾 Purr·opolis`, "opolis" in bougainvillea).
Drop a real `logo.svg` here when you have one.

## Imagery
No photographs are bundled. `CatCard` and the app screens fall back to colored gradient +
emoji placeholders when no `photo` URL is passed — supply real cat photos (warm, bright,
daytime, rounded frames per the brand) via the `photo` prop / your own asset pipeline.

## Icons
Not bundled. The system specifies **Lucide** (2px stroke) via CDN
(`https://unpkg.com/lucide@latest`), plus the approved emoji set 🐾 🐱 📍 ❤️ used decoratively.
