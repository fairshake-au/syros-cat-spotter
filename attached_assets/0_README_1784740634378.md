# Purropolis — handoff bundle

A clean, well-separated copy of the Purropolis design system for dropping into an
existing React/Replit app. Two buckets:

```
purropolis-handoff/
├─ code/                         (1) components, styles & theme — the stuff you import
│  ├─ theme/
│  │  ├─ styles.css              global entry — @imports every token file below
│  │  └─ tokens/
│  │     ├─ colors.css           color palette + semantic aliases (CSS custom props)
│  │     ├─ typography.css       font stacks, type scale, weights, tracking
│  │     ├─ spacing.css          4px spacing grid + layout widths
│  │     ├─ effects.css          radii, shadows, motion (easing/durations)
│  │     └─ fonts.css            webfont loader (Google Fonts @import)
│  └─ components/                one <Name>.jsx + <Name>.d.ts (+ .prompt.md docs) each
│     ├─ Button, IconButton
│     ├─ Tag, Badge
│     ├─ Input, Switch
│     ├─ Card, CatCard, StatTile, ProgressBar, Avatar
│     └─ TabBar
└─ assets/                       (2) images, fonts & logos
   ├─ fonts.css                  the Google Fonts loader (see note below)
   └─ README.md                  ← IMPORTANT: what does & doesn't exist as a binary
```

## How to integrate

1. **Load the theme once, globally.** Import `code/theme/styles.css` at your app root
   (e.g. in `main.jsx`/`index.tsx`, or link it in your HTML `<head>`). It pulls in every
   token file, so all `--color-*`, `--font-*`, `--space-*`, `--radius-*`, `--shadow-*`
   custom properties become available app-wide. The webfonts load via Google Fonts (see
   `assets/README.md`).

2. **Import components directly** — each is a plain React component that needs only React
   and the CSS custom properties (no CSS-in-JS lib, no other deps):

   ```jsx
   import { Button } from './purropolis-handoff/code/components/Button.jsx';
   import { CatCard } from './purropolis-handoff/code/components/CatCard.jsx';

   <Button variant="accent" size="lg">Chip in €5</Button>
   <CatCard name="Baklava" catId="SYR-0142" neighborhood="Vaporia"
            status="Desexed" statusTone="success" />
   ```

   Sibling components import each other by relative path (e.g. `CatCard` imports `Badge`
   and `Tag`), so keep the `components/` folder intact. Rename `.jsx` → `.tsx` if your app
   is TypeScript — the matching `.d.ts` files already describe every prop.

3. **Read the `.prompt.md`** next to each component for a one-line description, a usage
   snippet, and the full variant/prop list.

## Component API summary
- **Button** — `variant` primary·accent·secondary·ghost, `size` sm·md·lg, `block`, `iconLeft/Right`
- **IconButton** — circular; `variant` soft·solid·ghost·accent, `size`, required `label`
- **Tag** — chip; `tone` neutral·aegean·bougain·sun·terra·olive
- **Badge** — status pill w/ dot; `tone` success·warning·danger·info
- **Input** — `label`, `helper`, `error`, `iconLeft`
- **Switch** — `checked`, `onChange`, `label`
- **Card** — surface; `hover`, `flat`, `padding`
- **CatCard** — cat catalog entry (photo, name, mono ID, status, like, tags)
- **StatTile** — big-number stat; `value`, `label`, `icon`, `tone`
- **ProgressBar** — goal meter; `value`, `max`, `tone`, `label`
- **Avatar** — circular; `src`, `name` (initial fallback), `size`, `ring`
- **TabBar** — fixed frosted bottom nav; `items`, `active`, `onChange`

## Caveats carried over from the system
- Fonts are **Google Fonts substitutes** (Poppins / Nunito / Space Mono) — see `assets/`.
- **No logo binary** — the wordmark is rendered in type (🐾 Purr·opolis).
- Cat imagery in `CatCard`/screens uses **colored placeholders**; pass real `photo` URLs.
